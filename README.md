# Employee Document Portal

A Node.js web app for collecting employee details and documents, with a password-protected admin panel, editable form requirements, document download, search, delete, and Excel export.

## Deploy to Render
See `DEPLOY_TO_RENDER_HINGLISH.txt`. The included `render.yaml` configures a paid Render Starter service and a 1 GB persistent disk so employee records and uploads survive restarts/redeployments. Set a strong `ADMIN_PASSWORD` during setup. `SESSION_SECRET` is generated by Render.

## Local use (optional)
- Windows 10/11 and Node.js 20+
- Run `START_PORTAL.bat`
- Local data is stored in `data/portal-data.json`; uploaded documents are in `uploads/`.

## Important
The employee submission form is public to anyone who has the URL; it does not verify employee identity. Keep the GitHub repository private, use a strong admin password, test with dummy data first, and collect only necessary personal documents. Back up the persistent disk separately.
